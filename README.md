# Java Practice

Exercises I wrote while learning Java, from the basics up to object-oriented programming.

Each folder is a small standalone program. To run one:

```bash
cd 04_object_oriented_programming/inheritance
javac *.java
java Main
```

| Folder | Topics |
|---|---|
| `01_basics` | Hello world, variables and data types, `Scanner` input, swapping variables, `final`, `printf` formatting, `Random`, `Math`, a `switch` calculator |
| `02_arrays_and_collections` | Arrays, 2D arrays, for-each loop, `ArrayList`, nested `ArrayList`s, arrays of objects |
| `03_methods_and_strings` | Methods, method overloading, `String` methods |
| `04_object_oriented_programming` | Classes and objects, constructors and constructor overloading, local vs. instance variables, `toString()` override, passing objects as arguments, `static`, inheritance, method overriding, `super` |
| `05_mini_projects` | A drinks shop and a (work in progress) chicken shop |
